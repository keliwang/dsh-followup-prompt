# Followup Prompt（后续提示）

> 为 DeepSeek Harness 预测你的下一条消息：按 Tab 采用，绝不自动发送。

每轮回答结束后，插件会根据当前对话推测你接下来最可能说的话，并以灰色文字显示在空输入框中。按 **Tab** 把它变成可编辑的草稿；不需要时直接打字即可，预测会自动消失。

- **不打扰**：只在输入框为空时出现；失败或超时时什么都不显示，也不会弹出报错。
- **由你决定**：预测只是草稿，必须由你手动发送。
- **开箱即用**：默认使用当前会话的模型，无需额外依赖或服务端。

## 环境要求

- DeepSeek Harness `>=0.2.0 <0.3.0`（已在 0.2.1-rc.2 上验证）

## 安装

> [!WARNING]
> 安装会修改当前 profile 的 `package.json` 和 lock 文件，需要授予完整权限。建议先在一个可以随时丢弃的测试 profile 中试用。

1. 获取安装包，以下任选其一：
   - npm 包 `dsh-followup-prompt`（发布后可用）；
   - 在本仓库执行 `pnpm pack`，得到 `dsh-followup-prompt-<version>.tgz`。
2. 在 Harness 中让 agent 调用 `plugin_manager` → `install_bundle`，`target` 填写 `.tgz` 文件的**绝对路径**或 npm 包名。
3. 刷新页面。

> [!NOTE]
> 请通过 `.tgz` 或 npm 包安装，不要直接安装源码目录。目录安装时插件找不到 Harness 自带的依赖，会加载失败。

### 验证安装

1. 发送一个问题，等待回答结束，保持输入框为空。
2. 输入框中出现灰色的预测文字。
3. 按 Tab，文字进入输入框，并且**没有被发送**。

如果始终看不到预测，请参阅[常见问题](#常见问题)。

## 使用

回答结束且输入框为空时，预测会显示在原 placeholder 的位置，右侧带有 `Tab 接受` 提示。

| 操作 | 效果 |
|---|---|
| **Tab** | 预测写入输入框成为草稿，光标位于末尾，可继续编辑 |
| **Esc** 或点击 × | 关闭本次预测，本回合内不再出现 |
| 开始打字或输入法组字 | 预测隐藏 |
| 开始新回合或切换会话 | 预测隐藏 |

重新打开一个已结束的会话时，也会显示该会话最后一轮的预测；同一回合只会请求一次模型。

## 配置

可以在 **Settings → Plugins → Followup Prompt** 中修改，也可以直接编辑 profile patch 中本插件的 `config`。

> [!IMPORTANT]
> 直接编辑 patch 时，`config` 会被整体替换而非合并。即使只改一个字段，也要写出全部字段，可参考本包的 [`cordis.patch.yml`](cordis.patch.yml)。

**常用**

| 字段 | 默认值 | 说明 |
|---|---|---|
| `enabled` | `true` | 总开关。关闭后不再发出任何模型请求。 |
| `provider` / `model` | `''` / `''` | 用于预测的模型。留空则使用当前会话的模型；可改用更便宜的小模型。两项须同时填写，否则忽略。 |
| `reasoningEffort` | `'off'` | 可选 `''`、`off`、`low`、`high`、`max`。默认关闭推理以降低延迟和成本；`''` 表示沿用模型默认值。 |

**请求与上下文**

| 字段 | 默认值 | 说明 |
|---|---|---|
| `maxTokens` | `400` | 预测的输出 token 上限，推理 token 也计入。 |
| `timeoutMs` | `15000` | 单次预测的总超时，范围 2–30 秒。 |
| `maxTurns` | `0` | 只携带最近 N 轮对话；`0` 表示携带完整历史（推荐，缓存命中率更高）。 |
| `maxInputChars` | `20000` | 输入字符预算，超出时从最早的对话开始裁剪；`0` 表示不限制。 |

**行为**

| 字段 | 默认值 | 说明 |
|---|---|---|
| `prefetchOnTurnEnd` | `false` | 回合一结束就预先生成，即使你没有在看该会话。会为所有活跃会话产生费用。 |
| `prompt` | `''` | 高级选项：替换内置的预测指令。 |

## 费用与隐私

- **费用**：每次预测都是一次普通的模型请求，按所用 provider 正常计费。可以通过 `enabled`、`provider` / `model` 和 `maxInputChars` 控制成本。
- **数据去向**：预测会把当前会话历史发送给该会话正在使用的模型，与正常聊天处于同一信任范围。如果设置了 `provider` / `model`，则发送给你指定的模型。
- **不落盘**：预测只保存在内存中，不写入会话记录或文件，重启后即消失。
- **日志**：只记录耗时、token 数和结果等元数据，不记录对话内容。
- **无遥测**：不向任何第三方上报数据。
- **敏感内容**：没有服务端内容审核。如果预测中出现疑似密钥的文本，插件会在本地直接丢弃这条预测；无论如何，预测都需要你手动发送。

## 常见问题

<details>
<summary><b>一直看不到预测</b></summary>

- 确认 `enabled` 为 `true`。
- 使用非 DeepSeek 模型时，`reasoningEffort: 'off'` 可能不受支持，请改为 `''`。
- 被中断或出错的回合不会生成预测，新建的空会话也不会。
- 输入框中有文字或附件时，预测不会显示。

</details>

<details>
<summary><b>按 Tab 没有反应</b></summary>

斜杠命令菜单或其他弹出菜单打开时，Tab 由菜单处理。关闭菜单后再按 Tab 即可。

</details>

## 已知限制

- 预测的显示位置依赖 Harness 输入框的内部结构，Harness 升级后可能错位。遇到问题时，可以先把 `enabled` 设为 `false` 临时关闭。
- 预测请求不会出现在会话记录中，无法事后查看或重放。

## 卸载

1. 让 agent 调用 `plugin_manager` → `remove_bundle`，参数为 `dsh-followup-prompt`。
2. 刷新页面，必要时重启 Harness。

如果只是想暂时停用，把 `enabled` 设为 `false` 即可。
